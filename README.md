# sprint0gui

A Sample GUI For (VERY) Simple Settings Interface

## Requirements

- Rust v1.93.0, installed via https://rust-lang.org/tools/install/

## Installation

1. Clone the repository to a local directory

```sh
git clone https://github.com/uncleMobius/sprint0gui.git
```

2. Change into the directory created

```sh
cd ./sprint0gui/
```

3. Run the test code with Cargo

```sh
cargo test
```

4. Run the Rust code with Cargo

```sh
cargo run
```
